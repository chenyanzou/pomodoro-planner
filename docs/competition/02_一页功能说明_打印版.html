🍅 番茄计划（Pomodoro Planner）— 一页功能说明

暖纸工作室 / 暗夜书房双主题 · 纯前端本地持久化 · PWA 离线可用 · GitHub Pages 公开访问

在线网址：chenyanzou.github.io/pomodoro-planner
开源仓库：github.com/chenyanzou/pomodoro-planner
这个网页是干什么的？ 面向学习、备考与日常项目推进的在线番茄钟计划安排表。它将防漂移 60 刻度仪式感番茄钟、按日分时段计划表、阶段目标拆解与复盘可视化看板融合在一处；免注册打开即用，数据独立保存在本地浏览器并支持 JSON 备份与一键隔离演示。

① 仪式感番茄钟与沉浸模式（左侧 / 全屏）

  • 60 刻度多层 SVG 表盘：逐格点亮刻度、微光进度圆珠与呼吸光环；全局径向光晕随专注（暖红）与休息（鼠尾草绿）柔和过渡；基于时间戳防后台漂移并同步标签页倒计时。
  • 开始 / 暂停 / 重置 ↺ / 跳过 ⏭：结束自动播放 Web Audio 纯合成钟声并支持桌面通知。
  • 环境白噪音：内置「细雨声 / 柔和粉噪 / 暖壁炉低噪」纯代码合成音源 + 独立音量条，零外链且断网可用。
  • 艺术级沉浸模式（F / Esc）：暗调动态光晕屏保级全屏专注界面。

② 今日计划安排表（右侧主工作区）

  • 日期导航 & 三联进度卡：< / 日历选择 / > / 回到今天，实时展示番茄进度、已专注分钟与任务完成数，支持 未完成顺延 一键整理。
  • 定制胶囊快速录入：按 N 聚焦回车即建，定制分段器与浮层下拉菜单设定 时段、优先级、关联目标与预估番茄步进器。
  • 任务卡片微交互：左侧优先级色脊、番茄圆点阵、弹性勾选动效、▶ 绑定呼吸框、拖拽 / ↑↓ 排序、✎ 编辑弹窗、🗑 删除（5 秒撤销）；空态配手绘 SVG 插画与引导。

③ 目标拆解 & 复盘统计看板

  • 目标拆解页：迷你 SVG 环形进度、标识色顶条、截止倒计时胶囊、归档切换与删除二次确认；点 + 拆解为今日/指定日任务 直接落入计划表。
  • 复盘统计页（懒加载）：4 项周期 KPI、近 7/30 天 渐变柱状图（悬浮气泡明细）、交互式目标占比环图（悬停联动中心指标）及近 12 周热力图（月标 + 三联洞察卡）。
  • 专注历史流水：支持补录、编辑、撤销删除与分页加载更多，图表实时重算。

④ 全局工具、隔离演示与快捷键

  • 隔离演示与双主题（✨演示 · ☀/🌙 · ⚙）：默认纯净空态启动；小月亮旁一键进入/退出内存隔离演示模式（不覆盖个人数据）；暖纸浅色 / 暗夜书房深色切换；支持 JSON 备份与严格校验恢复；移动端配备悬浮玻璃底栏（390px 零溢出）。
Space 启停计时 R 重置本轮 N 新建任务
F 沉浸模式 123 切换三大视图 ? 快捷键速查

⑤ 30 秒上手使用步骤

STEP 1 · 列计划 / 体验演示
默认纯净空白工作区，可直接写下今日任务（或点顶栏 ✨ 演示 预览完整示例数据）；也可在「目标拆解」一键拆出每日安排。
STEP 2 · 沉浸专注
点击任务右侧 ▶ 绑定到番茄钟，按 Space 启动；开启细雨白噪音或按 F 进入全屏沉浸，切去查资料也不影响后台精准计时。
STEP 3 · 复盘备份
到点自动提示并计入任务与历史流水；每天结束在「复盘统计」看趋势、环图与 12 周热力图，一键顺延未完成项并导出 JSON 备份。
技术栈：React 19 + TypeScript + Vite 6 + Tailwind CSS v4 + 自定义轻量 SVG 图表 + Web Audio API + PWA（23 项单测） 版本：v1.1（v0.1 → v0.3 → v1.0 → v1.0.2 → v1.1 完整演进）
