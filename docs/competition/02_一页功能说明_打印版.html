🍅 番茄计划（Pomodoro Planner）— 一页功能说明

暖纸极简风格 · 纯前端本地持久化 · PWA 离线可用 · GitHub Pages 公开访问

在线网址：chenyanzou.github.io/pomodoro-planner
开源仓库：github.com/chenyanzou/pomodoro-planner
这个网页是干什么的？ 面向学习、备考与日常项目推进的在线番茄钟计划安排表。它将防漂移番茄计时器、按日分时段计划表、阶段目标拆解与复盘统计看板融合在一处；无需注册账号即可打开即用，每个访问者的数据独立保存在本地浏览器中并支持 JSON 一键导入导出备份。

① 番茄钟专注区（左侧 / 全屏沉浸）

  • 专注 / 短休 / 长休：自由切换阶段，圆点显示长休轮次进度；基于时间戳防后台漂移与刷新恢复，标签页标题实时同步倒计时。
  • 开始 / 暂停 / 重置 ↺ / 跳过 ⏭：完整控制流程；结束自动播放 Web Audio 纯合成钟声并支持浏览器桌面提醒。
  • 环境白噪音：内置「细雨声 / 柔和粉噪 / 暖壁炉低噪」纯代码合成音源 + 独立音量条，零外链且断网可用。
  • 沉浸模式（F / Esc）：一键淡出干扰项，进入极简大圆环全屏专注界面。

② 今日计划安排表（右侧主工作区）

  • 日期导航 & 顺延：< / 日历选择 / > / 回到今天，并提供 未完成顺延到今天·明天 一键整理。
  • 快速录入条：输入任务回车即建，可选 上午/下午/晚上/自由时段、高/中/低优先级、关联目标与预估番茄数。
  • 任务卡片按钮：勾选完成、▶ 绑定到番茄钟、拖拽手柄 / ↑↓ 调整顺序与跨时段移动、✎ 完整编辑弹窗、🗑 删除（带 5 秒撤销提示）。
  • 筛选与空态：按全部/待办/已完成或所属目标筛选；默认首次进入为纯净空白工作区，无演示数据干扰。

③ 目标拆解 & 复盘统计看板

  • 目标拆解页：新建/编辑/归档/删除长期目标，自动汇总关联任务番茄进度条、累计专注分钟数与截止倒计时；点 + 拆解为今日/指定日任务 直接落入计划表。
  • 复盘统计页（懒加载）：4 项周期 KPI（今日/本周/本月/连续专注天数）、近 7/30 天 SVG 柱状趋势图、目标分类占比环图与近 12 周热力图。
  • 专注历史流水：支持 补录专注记录、编辑时长备注或删除（可撤销），所有图表即时重算。

④ 全局工具、数据备份与快捷键

  • 演示模式与外观（✨演示 · ☀/🌙 · ⚙）：小月亮旁一键进入/退出内存隔离演示模式（不覆盖个人数据）；暖纸浅色 / 暖炭深色切换；自定义时长、导出 JSON 备份与严格校验导入恢复。
Space 启停计时 R 重置本轮 N 新建任务
F 沉浸模式 123 切换三大视图 ? 快捷键速查

⑤ 30 秒上手使用步骤

STEP 1 · 列计划
在右侧输入今日任务、选好时段与预估番茄数（或在「目标拆解」创建大目标并一键拆出任务），用拖拽或 ↑↓ 排定优先级顺序。
STEP 2 · 沉浸专注
点击任务右侧 ▶ 绑定到番茄钟，按 Space 启动；可打开细雨白噪音或按 F 进入全屏沉浸，切去查资料也不影响后台精准计时。
STEP 3 · 复盘备份
到点自动提示并计入任务与历史流水；每天结束在「复盘统计」看趋势与热力图，一键顺延未完成项，并可在 ⚙ 导出 JSON 永久备份。
技术栈：React 19 + TypeScript + Vite 6 + Tailwind CSS v4 + 自定义轻量 SVG 图表 + Web Audio API + PWA 版本：v1.0（含 v0.1 → v0.3 → v1.0 完整 Git 演进）
