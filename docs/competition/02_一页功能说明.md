# 🍅 番茄计划（Pomodoro Planner）— 一页功能说明

> **在线体验**：https://chenyanzou.github.io/pomodoro-planner/ ｜ **源码仓库**：https://github.com/chenyanzou/pomodoro-planner  
> **定位**：一款**免登录、纯前端本地持久化、暖纸极简风格**的在线番茄钟计划安排表，将「高效专注计时」与「每日日程排程、长期目标拆解、数据复盘统计」无缝结合，所有数据安全保存在用户本地浏览器并支持离线 PWA 与 JSON 备份。

---

## 一、三大核心视图与按钮功能总览

### 1. 今日专注（主页面：左侧番茄钟 + 右侧计划安排表）
- **计时阶段切换**（`专注` / `短休` / `长休`）：一键切换模式，底部圆点指示当前第几轮番茄（默认每 4 轮自动进入深度长休）。
- **核心计时控制**（`开始专注/暂停`、`重置 ↺`、`跳过 ⏭`）：基于 `endTimestamp` 时间戳防漂移，切后台或刷新页面均不丢失计时；网页标签页标题实时同步剩余倒计时。
- **环境白噪音与沉浸模式**：内置 Web Audio 纯代码合成的 `细雨声` / `柔和粉噪` / `暖壁炉低噪` 及独立音量条（免外链、离线可用）；点击 `沉浸模式`（或按 `F`）进入极简全屏专注界面。
- **日期导航与批量整理**（`<` / 日期选择器 / `>` / `回到今天` / `未完成顺延到今天·明天`）：支持自由翻阅任意日期计划，一键把未完成任务顺延至下一天。
- **今日进度与快速录入**：顶部实时显示当日完成番茄数与专注分钟数；输入框支持回车快速添加任务，并直接设定 **时段**（上午/下午/晚上/自由时段）、**优先级**（高/中/低）、**关联目标** 与 **预估番茄数**。
- **任务卡片操作**：勾选圆圈（完成/取消）、`▶`（绑定到左侧番茄钟开始专注）、拖拽手柄 / `↑↓`（同日排序与跨时段调整）、`✎`（打开完整编辑弹窗修改备注/日期/番茄数）、`🗑`（删除并弹出 **5 秒「撤销」提示**防误删）；支持按状态与目标筛选。

### 2. 目标拆解（顶部导航 / 移动端底部栏切换）
- **阶段目标卡片**：展示目标标识色、说明、截止日期倒计时、关联任务完成度与累计专注分钟数。
- **目标管理按钮**：`新建目标`、`✎ 编辑`、`归档/恢复`、`🗑 删除`（删除目标自动保留历史任务与专注记录快照）。
- **一键拆解联动**：点击卡片底部 `+ 拆解为今日/指定日任务`，即可把大目标直接拆成具体日期与时段的待办计划并一键跳转查看。

### 3. 复盘统计（路由级懒加载，首屏零负担）
- **4 项核心指标卡**：今日专注、本周累计、本月累计、连续专注天数（Streak）。
- **轻量定制 SVG 可视化**：支持 `近 7 天 / 近 30 天` 切换的专注趋势柱状图、按目标分类的时间占比环图、近 12 周专注热力图（悬停查看每日明细）。
- **专注历史流水**：支持 `补录专注记录`、`✎ 编辑时长/备注`、`🗑 删除（可撤销）`，修改后所有图表实时重算。

### 4. 顶栏全局工具与快捷键
- **演示模式切换**（`✨ 演示` / `退出演示`，位于小月亮按钮旁）：默认进入为干净的空白个人工作区；点击「演示」即刻加载完整示例任务、目标与多日复盘图表供快速体验，且**完全内存隔离，不会覆盖个人本地数据**，点击「退出演示」一键恢复。
- **外观切换**（`☀ / 🌙`）：暖纸浅色 / 暖炭深色一键切换（设置中可选跟随系统）。
- **设置与备份**（`⚙`）：自定义专注/短休/长休时长、自动流转开关、合成提示音试听、浏览器桌面通知授权，以及 **导出 JSON 备份 / 校验导入恢复 / 恢复演示数据 / 清空全部**。
- **键盘快捷键**（`?` 查看）：`Space` 启停计时 ｜ `R` 重置 ｜ `N` 新建任务 ｜ `F` 全屏沉浸 ｜ `1 / 2 / 3` 切换三大视图 ｜ `Esc` 退出弹窗或沉浸模式。

## 二、30 秒快速上手流程

1. **规划今日安排**：默认打开是干净无干扰的空白工作区（若想快速预览完整效果，可点顶部小月亮旁的 `✨ 演示` 进入隔离演示模式）；在右侧输入任务并设定时段与预估番茄数，可拖拽或点击 `↑↓` 排好先后顺序。
2. **绑定任务开始专注**：点击某条任务右侧的 `▶` 绑定到番茄钟，点击 `开始专注`（或按 `Space`）；需要隔绝干扰时按 `F` 进入沉浸模式并开启细雨白噪音。
3. **自动记录与复盘**：专注倒计时结束后自动播放柔和提示音、+1 任务番茄数并写入历史流水；切换到「目标拆解」查看大目标推进度，在「复盘统计」回顾趋势与热力图，必要时在 `⚙` 中一键导出 JSON 备份。
