# 🍅 番茄计划（Pomodoro Planner）— 一页功能说明

> **在线体验**：https://chenyanzou.github.io/pomodoro-planner/ ｜ **源码仓库**：https://github.com/chenyanzou/pomodoro-planner  
> **定位**：一款**免登录、纯前端本地持久化、暖纸工作室（Editorial Studio）与暗夜书房（Night Study）双主题风格**的在线番茄钟计划安排表，将「仪式感专注计时」与「每日日程排程、长期目标拆解、复盘可视化统计」无缝结合，所有数据安全保存在用户本地浏览器并支持离线 PWA 与 JSON 备份。

---

## 一、三大核心视图与按钮功能总览

### 1. 今日专注（主页面：左侧仪式感番茄钟 + 右侧计划安排表）
- **多层 SVG 仪式感表盘与阶段切换**（`专注` / `短休` / `长休`）：60 刻度逐格点亮、柔和渐变弧线、微光进度端点圆珠与运行时呼吸光环；背景径向光晕随专注（微暖红晕）与休息（鼠尾草绿晕）平滑过渡。
- **核心计时控制**（`开始专注/暂停`、`重置 ↺`、`跳过 ⏭`）：基于 `endTimestamp` 时间戳防漂移，切后台或刷新页面均不丢失计时；网页标签页标题实时同步剩余倒计时。
- **环境白噪音与艺术级沉浸模式**：内置 Web Audio 纯代码合成的 `细雨声` / `柔和粉噪` / `暖壁炉低噪` 及独立音量条（免外链、离线可用）；点击表盘右上角全屏按钮（或按 `F`）进入极简动态光晕屏保级全屏沉浸专注模式。
- **日期导航与批量整理**（`<` / 日历选择器 / `>` / `回到今天` / `未完成顺延到今天·明天`）：顶部三联数字仪表盘实时呈现番茄进度、已专注分钟与任务完成数，支持自由翻阅任意日期并一键顺延未完成项。
- **一体化快速录入条**：支持按 `N` 聚焦回车即建，全部下拉/分段控件均采用定制胶囊与浮层菜单（零原生丑样式），直接设定 **时段**（上午/下午/晚上/自由）、**优先级**（高/中/低）、**关联目标** 与 **预估番茄数步进器**。
- **任务卡片微交互**：左侧优先级色脊、番茄进度圆点阵、勾选完成弹性扩散动效、`▶` 绑定到番茄钟（激活态微呼吸框）、拖拽手柄 / `↑↓` 排序与跨时段移动、`✎` 编辑弹窗、`🗑` 删除（带 **5 秒撤销提示**）；空白日提供手绘风 SVG 空状态插画与一键「写下第一个计划 / 看看演示」引导。

### 2. 目标拆解（顶部导航 / 移动端悬浮玻璃底栏切换）
- **阶段目标卡片**：内置迷你 SVG 环形进度百分比、标识色顶条、截止日期紧迫度胶囊、关联任务完成度与累计专注分钟数。
- **目标管理与防误删**：顶部胶囊切换 `进行中 / 已归档`，支持 `新建目标`、`✎ 编辑`、`归档/恢复`、`🗑 删除`（带内联二次确认防误删，并自动保留历史任务与专注记录快照）。
- **一键拆解联动**：点击卡片底部 `+ 拆解为今日 / 指定日任务`，即可把大目标拆成具体日期与时段的待办计划并一键跳转查看。

### 3. 复盘统计（路由级懒加载，首屏零负担）
- **4 项核心指标卡**：今日专注、本周累计、本月累计、连续专注天数（Streak）。
- **定制轻量 SVG 可视化看板**：
  - `近 7 天 / 近 30 天` 渐变柱状趋势图（带 Y 轴刻度与悬停浮动气泡明细）；
  - 目标时间占比交互环图（悬停扇区或图例高亮联动中心占比与总分钟读数）；
  - 近 12 周圆角微光热力图（含月份标签与右侧「12 周总投入 / 活跃日均 / 单日峰值」三联洞察卡）。
- **专注历史流水**：按日期与结束时间精准排序，支持 `补录专注记录`、`✎ 编辑时长/备注`、`🗑 删除（可撤销）` 以及超出 20 条的分页「加载更多」，修改后所有图表实时重算。

### 4. 顶栏全局工具与快捷键
- **演示模式切换**（`✨ 演示` / `退出演示`，位于小月亮按钮旁）：默认进入为干净的空白个人工作区；点击「演示」即刻加载完整示例任务、目标与多日复盘图表，且**完全内存隔离，不覆盖个人本地数据**。
- **外观切换**（`☀ / 🌙`）：暖纸浅色 / 暗夜书房深色一键切换（设置中可选跟随系统）。
- **设置与备份**（`⚙`）：自定义专注/短休/长休时长（草稿态输入失焦校验）、自动流转开关、合成提示音试听、浏览器桌面通知授权，以及 **导出 JSON 备份 / 严格校验导入恢复 / 清空全部**。
- **键盘快捷键**（`?` 查看）：`Space` 启停计时 ｜ `R` 重置 ｜ `N` 新建任务 ｜ `F` 全屏沉浸 ｜ `1 / 2 / 3` 切换三大视图 ｜ `Esc` 退出弹窗或沉浸模式。

## 二、30 秒快速上手流程

1. **规划今日安排**：默认打开是无干扰的纯净空白工作区（想快速预览完整界面，可点顶部小月亮旁的 `✨ 演示` 或空状态里的「看看演示」进入隔离演示模式）；在右侧输入任务并设定时段与预估番茄数。
2. **绑定任务开始专注**：点击某条任务右侧的 `▶` 绑定到番茄钟，点击 `开始专注`（或按 `Space`）；按 `F` 进入沉浸模式并开启细雨白噪音，切标签页也不影响后台精准计时。
3. **自动记录与复盘**：专注结束自动播放柔和钟声、+1 任务番茄数并写入历史流水；在「目标拆解」追踪长期进度，在「复盘统计」回顾趋势与热力图，随时在 `⚙` 一键导出 JSON 备份。
