# 版本迭代演进日志（CHANGELOG）

本项目遵循真实、可独立编译运行的渐进式工程迭代，每个里程碑均对应 Git 仓库中的独立 Annotated Tag 与纯净源码快照。

---

## `v0.1` — 最小可用原型（MVP）
- **定位**：验证核心番茄钟计时准确性与本地任务持久化闭环。
- **核心交付**：
  - 搭建 React 19 + TypeScript + Vite 6 + Tailwind CSS v4 + Vitest 工程骨架与暖纸极简 CSS 主题令牌。
  - 实现本地时区安全日期工具（`date.ts`）与基于 `endTimestamp` 的防漂移番茄钟纯逻辑引擎（`timerEngine.ts`），支持刷新与后台切标签页恢复。
  - 实现版本化 `localStorage` 存储（主状态与高频计时状态分键存储）与分离式 `AppDataContext` / `TimerContext`。
  - 实现 `v0.1` 桌面双栏界面：SVG 环形番茄钟 + 今日任务基础增删改查与任务绑定，以及浅/深主题一键切换。
  - 质量门禁：12 项 Vitest 单元测试通过，构建产物 ~82 KB gzip。

## `v0.3` — 完整计划排程、目标拆解与复盘统计
- **定位**：从“待办清单”升级为“日程排程 + 目标拆解 + 数据复盘”完整效率系统。
- **相对 `v0.1` 的核心演进**：
  - **今日计划表升级**：新增日期前后切换与日历跳转、四时段分区（上午/下午/晚上/自由时段）、高/中/低优先级标签、完整任务编辑弹窗、同日与跨时段拖拽排序、未完成任务一键顺延、状态与目标筛选、删除 5 秒撤销 Toast。
  - **目标拆解视图（`GoalsView`）**：支持阶段/长期目标 CRUD、6 色暖纸标识色板、截止日期倒计时、任务番茄数与专注分钟数自动汇总、归档管理，以及「+ 拆解为今日/指定日任务」一键联动。
  - **复盘统计看板（`AnalyticsView`）**：采用 `React.lazy` 路由级懒加载（独立拆包仅 5.9 KB gzip），纯定制轻量 SVG 实现近 7/30 天柱状趋势图、目标分类占比环图与近 12 周热力图，并支持历史专注流水的手动补录、编辑与撤销删除。
  - **数据备份校验（`backup.ts`）**：实现 Schema v1 JSON 导出与严格运行时字段校验。
  - 质量门禁：新增统计聚合与备份校验单测，共 18 项 Vitest 单元测试全绿。

## `v1.0` — 前端视觉精修、沉浸体验、PWA 与线上部署版
- **定位**：打磨视觉与交互细节、补齐前端性能优化与跨端离线能力，完成质量严检并公开上线。
- **相对 `v0.3` 的核心演进**：
  - **纯净音频与沉浸专注**：基于 Web Audio API 纯代码合成结束钟声与 3 种白噪音（细雨声 / 柔和粉噪 / 暖壁炉低噪，零外链依赖），新增一键全屏沉浸模式（`ImmersiveOverlay`）、浏览器桌面通知与标签页实时倒计时。
  - **设置与快捷键**：新增设置与 JSON 导入导出备份弹窗（`SettingsModal`）、全局键盘快捷键（`Space`/`R`/`N`/`F`/`1`/`2`/`3`/`?`/`Esc`）及快捷键速查弹窗。
  - **移动端与 PWA**：新增移动端固定底部导航（`MobileNav`）、自定义暖纸番茄矢量图标（`favicon.svg`）、`vite-plugin-pwa` 离线 Service Worker 预缓存与 GitHub Actions 自动部署工作流。
  - **实测与独立代码审查修复（关键工程优化）**：
    - 修复 React 19 `setState` 批处理导致删除任务/记录 5 秒撤销 Toast 失效的问题；
    - 拆分 `TimerActionsContext` 与 `TimerTickContext`，彻底消除番茄钟每秒跳动引发的任务列表重渲染，并将完成副作用移出渲染期更新器；
    - 修复向下拖拽排序、跨时段上下移动逻辑与键盘/移动端可访问排序按钮；
    - 增加用户手势解锁 `AudioContext`、日期输入防清空校验与 `localStorage` 局部损坏元素过滤；
    - 提升暖炭深色主题次级文字与按钮对比度，并修复 390px 移动端视口网格横向溢出至 `0px`。
  - 质量门禁：22/22 单元测试全绿、桌面与移动端真实浏览器 QA 全项通过，成功上线 GitHub Pages。

## `v1.0.1` — 真实体验反馈迭代（纯净空白启动 + 隔离演示模式）
- **背景**：上线实测后，用户指出真实访问者默认不需要内置演示数据，应改为纯净空态启动，并提供独立的演示体验入口。
- **核心改动**：
  - `loadAppState` 默认与损坏恢复回退改为纯净空白工作区（`goals: []`、`tasks: []`、`sessions: []`）。
  - 在顶部小月亮（深浅主题切换）按钮旁新增 **「✨ 演示 / 退出演示」** 切换按钮，并在演示态顶部显示提示条。
  - `AppDataContext` 采用 `realState`（持久化 `localStorage`）与 `demoState`（纯内存临时态）双轨隔离设计：进入演示模式可任意增删改与跑图表，退出演示瞬间无损恢复个人真实数据。
  - 质量门禁：更新存储单测并全量通过（22/22），推送 GitHub 自动更新线上站点。
