## 3. 本地快速运行与验证（可选，评委也可直接访问线上网址）

环境要求：Node.js >= 20

```bash
cd 04_核心项目源码_v1.1
npm install
npm run dev      # 启动本地开发预览
npm test         # 运行 23 项 Vitest 核心逻辑单元测试
npm run build    # 执行 TypeScript 类型检查 + 生产构建（含 PWA 生成）
```
