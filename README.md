# 🍅 番茄计划 · Pomodoro Planner

一款**暖纸极简风格**的纯前端番茄钟与日程计划安排表应用，部署在 GitHub Pages 上，**免登录、开箱即用、离线可用**，每个人的计划与专注记录均安全保存在本地浏览器中并支持 JSON 一键备份。

> **在线体验地址**：https://chenyanzou.github.io/pomodoro-planner/  
> **GitHub 开源仓库**：https://github.com/chenyanzou/pomodoro-planner

## ✨ 核心亮点

- **防漂移番茄钟引擎**：基于 `endTimestamp` 时间戳推演，切换标签页、系统休眠或刷新页面均不丢状态；支持自定义专注/短休/长休时长与长休周期，标签页标题实时显示倒计时。
- **纯净沉浸体验**：基于 Web Audio API 纯代码合成柔和提示音与 3 种白噪音（细雨声 / 柔和粉噪 / 暖壁炉低噪），**零外部音频 CDN 依赖**；支持一键全屏沉浸模式与浏览器桌面提醒。
- **今日计划安排表**：支持按日切换、上午/下午/晚上/自由时段分组、高/中/低优先级、拖拽排序与跨时段调整、完整编辑弹窗、未完成任务一键顺延、删除 5 秒撤销。
- **阶段目标拆解**：创建长期/阶段目标并绑定标识色与截止日期，自动汇总关联任务番茄进度与专注时长，一键把大目标拆解为具体日期的计划任务。
- **路由级懒加载复盘看板**：4 项周期 KPI 卡片 + 近 7/30 天自定义 SVG 柱状趋势图 + 目标分类占比环图 + 近 12 周热力图 + 支持补录/编辑/删除的历史专注流水。
- **前端工程与体验优化**：
  - 暖纸浅色 / 暖炭深色 / 跟随系统三态切换，首屏防闪烁；
  - 统计模块 `React.lazy` 按需拆包（独立 chunk 仅 ~6 KB gzip），无重型图表库与外部阻塞字体；
  - 完整 PWA（Manifest + Service Worker 预缓存），支持添加到手机/电脑主屏幕离线运行；
  - 全面键盘快捷键（`Space`、`R`、`N`、`F`、`1/2/3`、`?`、`Esc`）。

## 🗂 迭代演进记录

- **`v0.1`**：防漂移番茄钟引擎 + 今日基础待办清单 + `localStorage` 本地持久化 MVP。
- **`v0.3`**：完整日排程（日期导航/时段/优先级/拖拽/顺延/撤销）、目标拆解视图、懒加载 SVG 复盘看板、严格校验 JSON 备份与 18 项 Vitest 核心逻辑单测。
- **`v1.0`**：Web Audio 纯合成提示音与白噪音、全屏沉浸模式、全局快捷键、移动端底部导航、PWA 离线支持与 GitHub Pages 自动部署。

## 🛠 本地运行与测试

```bash
npm install
npm run dev       # 本地开发预览
npm test          # 运行 Vitest 单元测试
npm run build     # TypeScript 检查 + 生产构建
```
